# ☕ Cafe React — เวอร์ชั่นกวนตีน (Homework)

โปรเจกต์ร้านกาแฟเล็กๆ ใช้ **React 19 + Vite + Tailwind CSS 4**
เดิมทีเป็นหน้าเว็บธรรมดาๆ เหมาะกับน้องหมาน้องแมว แต่ขอทำเป็นร้านกาแฟที่
**กวนตีนได้ตามคำขอ** 😎

## วิธีรัน

```bash
npm install     # ติดตั้งของที่ต้องใช้ (ครั้งแรกครั้งเดียว)
npm run dev     # เปิด server แล้วไปที่ http://localhost:5173
```

## หน้าเว็บนี้ประกอบด้วยคอมโพเนนต์อะไรบ้าง

```
App (คอมโพเนนต์แม่ / จัดการ state กลาง)
├── Navbar    → แถบเมนูบนสุด + ปุ่ม Cart พร้อมตัวเลข badge
├── Hero      → ส่วนหัว หน้ากล้าๆ (ข้อความกวนตีนอยู่ตรงนี้)
├── Notice    → แถบแจ้งเตือนที่ข้อความเปลี่ยนตามจำนวนที่สั่ง
├── Menu      → รายการเมนู (map เอาข้อมูลจาก data/menu.js)
│   └── MenuCard → การ์ดเมนูแต่ละแก้ว
└── Cart      → ตะกร้า แสดงรายการ + ยอดรวม
```

## React concept ที่แฝงอยู่ (แบบไม่ต้องซีเรียส)

| Concept | อยู่ที่ไหน | อธิบายแบบง่ายๆ |
|---|---|---|
| `useState` | `App.jsx` | เป็นตัวเก็บ "ของที่อาจเปลี่ยน" เช่น ตะกร้า เริ่มต้นเป็น `[]` |
| `setCart` | `App.jsx` | ฟังก์ชันไว้แก้ตะกร้า **ห้ามแก้ตัวแปร cart ตรงๆ** |
| `props` | ทุกคอมโพเนนต์ | การส่งข้อมูลจากแม่ → ลูก เช่น ส่ง `cartCount` ให้ Navbar |
| `map()` | `Menu.jsx`, `Cart.jsx` | วนลูปแสดงรายการจาก array |
| `reduce()` | `App.jsx`, `Cart.jsx` | เอาเลขมารวมกัน เช่น รวมราคา |
| Conditional Rendering | `Cart.jsx`, `App.jsx` | "ถ้าเงื่อนไขนี้ ให้แสดงแบบนี้" เช่น ตะกร้าว่าง → แสดงข้อความ |
| Props Drilling | ทั้งแอป | ข้อมูลถูกส่งผ่านเป็นชั้นๆ จาก App ลงไปลูกๆ |

## ของใหม่ที่เพิ่มเข้าไป (กวนตีนแบบมีเหตุผล)

### 1. แถบแจ้งเตือนที่ "คิดเองได้" (`App.jsx`)
ข้อความข้างบนเปลี่ยนไปตามจำนวนที่สั่งในตะกร้า:

- ไม่ได้สั่ง → *"ยังไม่สั่งอะไรเลย กดปุ่มบวกก็ได้นะ ไม่กัด"*
- สั่ง 1–2 แก้ว → *"เริ่มสั่งแล้ว เยี่ยม! ยังไงซะก็ดื่มไม่หมดอยู่ดี"*
- สั่ง 3–5 แก้ว → *"โห หลายแก้วจัง ใครดื่มหมดรับผิดชอบเองนะ"*
- สั่งเกิน 5 → *"เบาๆ หน่อยครับคุณลูกค้า ร่างกายคือ state ใช้แล้วไม่คืนกับใคร"*

> นี่คือตัวอย่าง **Conditional Rendering** ที่อ่านค่าจาก state แล้วแสดงผลต่างกัน
> พอ value เปลี่ยน React จะ re-render ให้เอง ไม่ต้องไปแตะ DOM มือ

### 2. คำโปรยกวนตีนใน Navbar และ Hero
- Navbar มี subtitle ว่า *"กาแฟเราดีจริง รับประกันว่ามั่วนะ"*
- Hero พาดหัวว่า *"ชงกาแฟด้วย React หรือจะมานั่งมั่วนี่ก็ได้"*

### 3. คำอธิบายเมนูกวนตีน (`data/menu.js`)
เช่น *"ฟองหนาแบบ Promise ที่ไม่เคย Reject"* หรือ
*"เหมาะกับคนชอบแก้บั๊กทั้งคืน"* — แค่แก้ข้อมูลในไฟล์เดียว การ์ดก็เปลี่ยนตาม
(เพราะ `Menu.jsx` วนลูปเอาข้อมูลจากตรงนี้มาแสดง)

### 4. ข้อความในตะกร้า
- ตะกร้าว่าง → *"ว่างยิ่งกว่าความรู้สึกตอนเจอ error ก่อน deadline"*
- แถบยอดรวม → *"ยอดรวม (จะร้องไห้ทีหลังก็ได้)"*

## โครงสร้างไฟล์ที่เกี่ยวข้อง

```
src/
├── App.jsx               # state กลาง + แถบ Notice + footer
├── components/
│   ├── Navbar.jsx        # แถบเมนูบนสุด
│   ├── Hero.jsx          # ส่วนหัว
│   ├── Menu.jsx          # แสดงรายการเมนูทั้งหมด
│   ├── MenuCard.jsx      # การ์ดเมนู 1 แก้ว
│   └── Cart.jsx          # ตะกร้า + ยอดรวม
└── data/
    └── menu.js           # ข้อมูลเมนู (แก้ตรงนี้แล้วเว็บเปลี่ยนตาม)
```
